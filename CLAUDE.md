# relay-messenger-support — Jekyll GitHub Pages support site for Relay messenger (macOS desktop client)

## Deploy Configuration

| Field | Value |
|---|---|
| **Platform** | GitHub Pages (Jekyll, `jekyll-theme-cayman`) |
| **Deploy trigger** | Push to `main` — GitHub Pages builds automatically from `docs/` |
| **Deploy status** | Auto-deploy on merge to `main`; no manual step needed |
| **Production URL** | https://lubos-buracinsky.github.io/relay-messenger-support |
| **Rollback** | Revert the commit on `main` and push — Pages rebuilds automatically |
| **CI** | No GitHub Actions present; GitHub Pages built-in Jekyll pipeline only |
